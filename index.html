Source integrity

Methodology. Macro Data Watch publishes latest official observations, not media summaries or market-consensus estimates. Direction compares the latest observation with the immediately preceding reported period on the same basis. A failed source does not overwrite a valid observation; the last-known-good value remains visible and the affected source is marked degraded.
